# Course Outline

# CLT 101: COMPUTER LITERACY I

## General Objectives
* To identify the major components of a computer system and evaluate its
potential and limitations;
* To explain the purpose of a computer operating system and the uses of
commercially available software;
* To describe basic computer functions and use correct computer terminology.


## Performance objectives:

### 1. Introduction to the Computer
-  Explain Computer Literacy. Define a computer; distinguish between four
  types of computers – the microcomputer, minicomputer, mainframe and
  supercomputer. State the basic structure of the computer and describe the
  computing cycle. Distinguish between hardware and software.
  Distinguish between system software and application software. Define and
  explain computer word. Identify the professional users of the computer.


### 2. The Microcomputer
-  Describe the components of a microcomputer. Describe the components of the
  system unit in a microcomputer.


### 3. Input/Output and Secondary Memory
-  Explain the difference between keyboard and direct-entry input devices.
  Identify keyboard entry devices: keyboards and terminals. Identify some direct
  entry devices used with microcomputers. These include the Mouse, Touch
  screen, Light pen, Digitizer, Digital camera, Image scanner, Fax, Bar code
  reader, MICR and OCR, OMR and Voice-input devices. Describe monitors
  (cathode-ray tube and flat panel) and monitor standards (CGA, EGA, VGA,
  Super VGA and XGA). Describe printers (Ink-jet, Laser, Dot matrix, Thermal)
  and plotters (Pen, Ink-jet, electrostatic and direct image). Describe voice-
  output devices. Contrast direct access and sequential access storage. Describe
  the following kinds of disks: internal hard disks, hard-disk cartridges and hard-
  disk packs. Describe the different types of optical disks: CD-ROM, CD-R,
  erasable, and DVD. Describe magnetic tape streamers and magnetic tape reels.


### 4. Microcomputer Operating Systems
-  Identify the programs that constitute system software: bootstrap loader,
  diagnostic routines, basic input-output systems and operating system. Identify
  the five most important types of microcomputer operating systems: DOS,
  Microsoft Windows, OS/2 Warp, Macintosh and Unix. Discuss the features of
  Microsoft Windows programs. Discuss the features of OS/2 Warp. Describe
  the Macintosh operating system. Describe the Unix operating system.


### 5. Data Communications and Networks
-  Describe the most common data communications channels and media.
  Describe data types, signal types, and some of the communications devices
  used today. Explain network architecture – configurations and strategies.
  Describe local area, metropolitan area, and wide area networks.


### 6. The Internet / E-Mail
-  Describe the Internet and describe the most common applications on it. List
  the most popular programs or utilities available to help you locate and use
  Internet resources. List providers of access to the Internet and the type of
  connections used. List some discussion groups available on the Internet. List
  the commonly used services available on the Internet. Describe the World
  Wide Web, and understand browsers, Web pages, search tools, and Web
  utilities.
