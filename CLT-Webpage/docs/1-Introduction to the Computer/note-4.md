# Hardware vs Software

The primary difference between **hardware** and **software** is that **hardware** refers to the physical components of a computer, while **software** refers to a collection of computer programs that contain instructions for the computer. 

## 1. Hardware

**Hardware** refers to the physical components of a computer. These are parts that can be physically inside the computer or connected to it.

### Examples of Hardware

1. **Monitor**
   A monitor is an electronic visual display device used to display information from the computer.

2. **Motherboard**
   A motherboard holds the main components of a computer, such as memory.

3. **CPU (Central Processing Unit)**
   The CPU executes the commands and instructions of the computer.

4. **RAM (Random-Access Memory)**
   RAM is a type of memory that can be accessed quickly by the computer. It does not store permanent data.

5. **Expansion Card**
   An expansion card improves or adds specific functions to a computer. Examples include video cards and graphics cards.

6. **Power Supply**
   A power supply converts AC power into low-voltage DC power required by the various components of a computer.

7. **Optical Disk Drive**
   An optical disk drive uses lasers to obtain information from optical disks such as CDs, DVDs, and Blu-ray discs.

8. **Hard Disk Drive (HDD)**
   A hard disk drive is a device used to store and retrieve data. It uses rapidly rotating disks and magnets to store information.

9. **Keyboard**
   A keyboard is a typewriter-like input device used to enter keystrokes into a computer.

10. **Mouse**
    A mouse is a pointing device that allows users to point at and select different objects on the computer screen. 

---

## 2. Software

**Software** is a collection of computer programs containing data and instructions that tell a computer how to perform different tasks.

Software is stored in the memory of a computer or on an external storage device. It acts as the **brains behind the hardware**, telling the hardware what functions to perform.

Unlike hardware, **software cannot be physically touched**. Although the storage device on which software is stored can be touched, the software itself cannot. 

### Examples of Software

* **Computer Games** – Road Rush, Grand Theft, etc
* **Text Editing Software** – Microsoft Word, Power Point, Excel
* **Photo Editing Software** – Adobe Photoshop
* **Operating Systems** – macOS, Windows, Linux
* **Media Storage/Playback Software** – iTunes, Windows Media Player, VLC
* **And many more** 

---

## 3. Difference Between Hardware and Software

| **Hardware**                                             | **Software**                                                             |
| -------------------------------------------------------- | ------------------------------------------------------------------------ |
| Refers to the physical components of a computer.         | Refers to computer programs and instructions.                            |
| Can be physically touched.                               | Cannot be physically touched.                                            |
| Includes components inside or connected to a computer.   | Is stored in computer memory or external storage devices.                |
| Examples include CPU, RAM, keyboard, mouse, and monitor. | Examples include Windows, Microsoft Word, Photoshop, and computer games. |
| Provides the physical platform for computer operations.  | Provides instructions that tell hardware what to do.                     |
